# Ticker logos

Real marks for thirteen of the fifteen tickers, taken from the MIT-licensed
`us-stock-logos` package and copied here rather than imported - the package
ships around twelve thousand files and this needs thirteen.

`GOOGL.png` is the package's `GOOG` mark; Alphabet's two share classes share a
logo. `SPY` and `QQQ` have none: the set covers companies well and index ETFs
badly, so those two fall back to a lettered tile in the fund's colour.

To add or replace one, drop a square PNG named by ticker. Anything missing
degrades to the tile, so the grid never breaks on a file that is not here.

Company logos are trademarks of their owners. They are used here to name the
share a pack pays out, which is how a brokerage uses them - not as a claim of
any endorsement.
